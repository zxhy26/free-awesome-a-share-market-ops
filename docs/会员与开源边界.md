# 会员与开源边界

## 保持不变的会员规则

- 首页复盘面板不要求会员。
- 政策新闻、下周大事件、机构动向、历史回放和个股搜索要求有效会员。
- 月付为 72 元，有效期 30 天。
- 包年为 699 元，有效期 365 天。
- 激活码与本机设备码绑定，并由 RSA 公钥验证签名。
- 会员到期后受保护功能重新锁定。

## 不公开的内容

- `会员私钥.pem`
- 商户号、API 密钥、支付回调密钥和生产环境变量
- 用户订单、设备码、激活记录和授权文件
- 正式会员实时数据服务与专属内容源

## 公开源码中的保护方式

`app/backend/会员授权服务.js` 负责校验设备码、激活码签名和有效期。`app/backend/复盘同步服务.js` 在返回受保护页面或接口前检查会员状态；未激活时，页面请求重定向到会员中心，接口返回 HTTP 402。

公开源码中的授权公钥只能验证激活码，不能签发激活码。签发私钥由创作者独立保存。

## 技术限制

任何完全公开并在用户本机执行的代码，都无法阻止第三方修改其本地副本。因此，官方付费边界依赖以下组合：

- 官方签名的激活码
- 不公开的签发私钥
- 不公开的正式会员内容和生产数据凭据
- 官方发布渠道与会员服务

自行修改或重新分发的非官方版本不代表官方会员服务。
