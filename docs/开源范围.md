# 开源范围

## 已公开内容

- 前端页面、样式和交互逻辑
- Node.js 本地服务与数据处理代码
- Windows 单文件启动器源码
- 构建、语法检查和公开仓库检查脚本
- 用于开发演示和结构兼容的数据样本

## 不包含的内容

- 私钥、访问令牌和生产环境配置
- 真实用户数据和运行日志
- 未获再分发授权的第三方数据
- 外部商业数据服务的账号和凭据

## 数据说明

仓库中的市场数据文件用于开发、调试和格式兼容，不应视为实时行情源。使用者应自行接入具有合法授权的数据来源，并核验交易日、时间戳和统计口径。

## 贡献要求

修改和再分发应遵守 GNU AGPL v3，并保留许可证及版权说明。提交数据源相关改动时，请说明来源、授权状态、字段定义和验证方法。
