# Open-Source Scope

## Included

- Frontend pages, styling, and interaction logic
- Node.js local services and data-processing code
- Windows single-file launcher source
- Build, syntax-checking, and public-source audit scripts
- Data samples for development and format compatibility

## Not Included

- Private keys, access tokens, and production configuration
- Real user data and runtime logs
- Third-party data without redistribution rights
- Accounts and credentials for external commercial data services

## Data

Market-data files in the repository are intended for development, debugging, and format compatibility. They must not be treated as a real-time market feed. Users should connect legally authorized data sources and validate trading dates, timestamps, and statistical definitions.

## Contributions

Modifications and redistribution must comply with the GNU AGPL v3 and preserve the license and copyright notices. Changes involving data sources should document provenance, licensing status, field definitions, and validation methods.
