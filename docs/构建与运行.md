# 构建与运行

## 环境

- Windows 10 或 Windows 11
- Node.js 20 或更高版本
- PowerShell 5.1 或更高版本
- 桌面封装时需要 Microsoft Edge WebView2 Runtime

## 启动本地服务

在仓库根目录执行：

```powershell
npm start
```

默认服务地址：

```text
http://127.0.0.1:18765/app/
```

可通过环境变量修改端口：

```powershell
$env:A_SHARE_REVIEW_PORT = "18766"
npm start
```

## 源码检查

```powershell
npm test
```

检查内容包括：

- 所有 JavaScript 文件可通过 `node --check`
- 仓库不存在会员签发私钥
- 仓库不存在常见密钥或令牌格式
- 会员保护页面和接口仍在授权映射中
- 月付、包年价格和三张会员中心二维码保持完整

## Windows 单文件启动器

`windows-launcher/单文件启动器.cs` 是当前单文件释放启动器源码。它要求将完整运行载荷 ZIP 和对应 SHA256 作为嵌入资源编译。

公开仓库不包含生产会员私钥、生产支付凭据和官方发布包中的正式会员数据。自行构建的版本应使用自己的运行载荷和明确的数据授权。
