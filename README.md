# 大A后勤部

大A后勤部是一套面向 A 股盘中观察和收盘复盘的轻量桌面应用。项目主体使用原生 HTML、CSS、JavaScript 和 Node.js，Windows 版通过本地服务与 WebView2 运行。

当前公开源码对应桌面会员版 `2.6.5`。

## 功能范围

- 主要指数分时、成交额和板块资金拐点标注
- 二级行业与概念板块资金流向
- 涨停、跌停、昨日涨停延续和昨日炸板修复
- 市场结构、赚钱效应与历史交易日对比
- 政策新闻、下周大事件、机构动向、历史回放和个股搜索
- 本机设备码、会员套餐、支付入口、激活码和到期倒计时

## 开源与会员

本项目采用“开源代码 + 付费会员内容”的模式：

- 首页复盘面板保持可查看。
- 政策新闻、下周大事件、机构动向、历史回放和个股搜索继续由会员授权控制。
- 月付价格保持 `72 元 / 30 天`，包年价格保持 `699 元 / 365 天`。
- 微信、支付宝和创作者二维码保留在会员中心。
- 仓库仅包含授权公钥，不包含激活码签发私钥、商户密钥、支付回调密钥或正式会员数据服务凭据。
- `app/data` 中的数据用于开发演示和结构兼容，不代表实时会员内容。

开源代码允许审查和自行构建，但不会附带官方会员服务权利。官方会员内容、实时数据服务和激活授权仍按会员规则提供。技术边界详见 [会员与开源边界](docs/会员与开源边界.md)。

## 本地运行

要求 Node.js 20 或更高版本：

```powershell
npm start
```

浏览器打开：

```text
http://127.0.0.1:18765/app/
```

运行公开源码检查：

```powershell
npm test
```

完整说明见 [构建与运行](docs/构建与运行.md)。
